# 🛠️ Skill: React 19 Functional UI Components

> **Phân loại**: `FRONTEND` | **Tính khả dụng**: Toàn bộ 14 vai trò Swarm (Universal)

## 1. Mô Tả Nhiệm Vụ
Lập trình component React 19 tối ưu, hỗ trợ Server Actions, Tailwind CSS và TypeScript nghiêm ngặt.

## 2. Công Cụ & MCP Được Kích Hoạt
- `tsx_builder, prettier_linter`

## 3. Quy Trình Thực Thi Chuẩn
1. Viết component dạng functional thuần khiết với generic TypeScript props.
2. Áp dụng utility classes của Tailwind CSS.
3. Tránh re-render không cần thiết bằng useMemo và useCallback.

## 4. Tiêu Chuẩn Nghiệm Thu (Definition of Done)
- Thực hiện hoàn tất không có cảnh báo lỗi.
- Ghi nhận nhật ký suy nghĩ và cập nhật trạng thái vào CSDL SQLite `.agents/db.sqlite`.
