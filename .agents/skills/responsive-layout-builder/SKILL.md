# 🛠️ Skill: Responsive Multi-Form Factor Layout

> **Phân loại**: `FRONTEND` | **Tính khả dụng**: Toàn bộ 14 vai trò Swarm (Universal)

## 1. Mô Tả Nhiệm Vụ
Thiết kế layout co giãn thích ứng mượt mà trên Desktop (1440px), Tablet (1024px) và Mobile (390px).

## 2. Công Cụ & MCP Được Kích Hoạt
- `media_query_helper, grid_tuner`

## 3. Quy Trình Thực Thi Chuẩn
1. Áp dụng CSS Grid và Flexbox linh hoạt.
2. Xếp dọc thanh bên trên màn hình nhỏ và mở rộng khi trên desktop.
3. Ngăn ngừa tràn khung hình (RenderFlex overflow).

## 4. Tiêu Chuẩn Nghiệm Thu (Definition of Done)
- Thực hiện hoàn tất không có cảnh báo lỗi.
- Ghi nhận nhật ký suy nghĩ và cập nhật trạng thái vào CSDL SQLite `.agents/db.sqlite`.
